### 2. Organización del Árbol de Directorios (Monorepo Desacoplado)

```text
adi-inventory-crm/
├── docs/                        # Documentación SDLC sincronizada en Markdown
│   ├── 00-reconocimiento-del-problema/
│   ├── 01-viabilidad-temprana/
│   └── 02-project-kickoff/
├── backend/                     # API RESTful del Gestor de Inventario
│   ├── src/
│   │   ├── config/              # Variables de entorno y configuración de BD
│   │   ├── controllers/         # Controladores HTTP (Catalog, Stock, Receipts)
│   │   ├── models/              # Modelos Relacionales (Brand, Model, SKU, Variant, Receipt)
│   │   ├── services/            # Lógica de Negocio y procesamiento de Lotes
│   │   └── utils/               # Helpers y compresión de imágenes
│   ├── tests/                   # Pruebas unitarias y de integración
│   ├── Dockerfile
│   └── package.json / requirements.txt
├── frontend/                    # Panel de Administración Web (CRM/Gestor)
│   ├── src/
│   │   ├── components/          # Componentes UI (Tabla de stock, Ingesta de Lotes, Colillas)
│   │   ├── pages/               # Vistas (Dashboard, Catálogo, Lotes, Configuración)
│   │   ├── services/            # Cliente API (Fetch/Axios a Backend)
│   │   └── styles/              # Estilos CSS responsivos
│   ├── public/
│   └── package.json
├── docker-compose.yml           # Orquestación de entorno local (Backend + BD)
├── .gitignore
└── README.md
```

### 3. Reglas de Mantenimiento de Repositorio
- Ningún archivo de configuración confidencial (`.env`) debe subirse al repositorio.
- Todos los entregables finales de documentación deben guardarse exclusivamente en la carpeta `/docs` respetando el formato Markdown traducido.
