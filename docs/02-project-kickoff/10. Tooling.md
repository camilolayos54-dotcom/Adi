### 2. Ecosistema de Herramientas de Desarrollo

| Categoría | Herramienta Elegida | Uso Específico en Adi |
| --- | --- | --- |
| **IDE / Editor** | VS Code / JetBrains | Desarrollo de Backend, Frontend y Documentación |
| **Control de Versiones** | Git + GitHub | Gestión de repositorios, ramas e integración de PRs |
| **Pruebas de API** | Postman / Thunder Client | Validación manual y automatizada de los endpoints REST del Gestor |
| **Contenedores** | Docker & Docker Compose | Entorno relacional PostgreSQL y API replicable localmente |
| **CI / CD** | GitHub Actions | Ejecución automatizada de linter y pruebas en cada PR |
| **Monitoreo de Errores** | Sentry / Logs Estructurados | Captura de errores en el backend durante la ingesta por lotes |

### 3. Automatización de Entorno
Comando de arranque unificado en local: `docker-compose up --build`.
