# 9. Definition of Done (DoD) y Definition of Ready (DoR)

### 1. Metadatos del Documento
**Proyecto:** Adi  
**Fase:** 2 — Project Kickoff  
**Entregable:** 9 de 13  
**Estado:** Aprobado  

### 2. Definition of Ready (DoR — Requisitos Listos para Desarrollar)
Una historia de usuario o requisito técnico está **Listo para Iniciar** si:
- Tiene un objetivo de negocio claro acotado al Gestor de Inventario.
- Los criterios de aceptación están definidos cuantitativamente.
- Las dependencias de base de datos relacional y datos de calzado están resueltas.
- Ha sido revisada y aprobada por el Tech Lead.

### 3. Definition of Done (DoD — Característica Finalizada)
Una característica técnica está **Definitivamente Terminada** si:
- El código cumple con las reglas de estilo y tipado (ESLint / Prettier sin advertencias).
- Las pruebas unitarias e integración han sido escritas y pasan al 100%.
- El Pull Request ha sido revisado y aprobado por el Tech Lead.
- La funcionalidad funciona en el entorno de Staging sin errores relacionales de stock.
- La documentación técnica y de usuario ha sido actualizada en la carpeta `/docs`.
