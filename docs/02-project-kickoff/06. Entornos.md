### 2. Matriz de Entornos de Ejecución

| Entorno | Propósito | Infraestructura / Hosting | Base de Datos | URL / Acceso |
| --- | --- | --- | --- | --- |
| **Local (Dev)** | Desarrollo activo y pruebas unitarias | `localhost` / Docker Compose | PostgreSQL Local / SQLite Dev | `http://localhost:3000` (Front) / `http://localhost:4000` (API) |
| **Staging (QA)** | Pruebas de integración e ingesta de lotes real | Cloud Container (Render/Railway) | PostgreSQL Staging Isolated | `https://staging-crm.adi.internal` |
| **Production** | Operación real del Gestor de Inventario Adi | Cloud Managed Container | PostgreSQL Production (Backups diarios) | `https://crm.adi.com.co` |

### 3. Gestión de Variables de Entorno (`.env`)
Variables obligatorias requeridas en la plantilla `.env.example`:
- `PORT`: Puerto de ejecución del servidor Backend.
- `DATABASE_URL`: Cadena de conexión cifrada a la base de datos relacional.
- `JWT_SECRET`: Clave secreta para la firma de tokens de autenticación de operadores.
- `STORAGE_BUCKET_URL`: URL del CDN/Bucket para imágenes de tenis.
- `APP_ENV`: Entorno activo (`development`, `staging`, `production`).
