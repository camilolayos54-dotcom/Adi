# 1. Identidad del Proyecto

### 1. Metadatos del Documento
**Proyecto:** Adi  
**Fase:** 2 — Project Kickoff

**Estado:** Aprobado  

### 2. Identidad Nominal y Mandato
- **Codename Técnico:** `adi-inventory-crm`
- **Versión de Arranque:** `v0.1.0-alpha`
- **Estado de Mandato (Fases 0 y 1):** Go
- **Implicación Arquitectónica Principal:** Desarrollo de Software Customizado. Arquitectura desacoplada: API de Gestión de Inventario relacional (Backend) y Panel de Administración Web responsivo (Frontend).

### 3. Hipótesis Central de Valor
Un gestor de inventario especializado en calzado deportivo con esquema relacional para marcas, modelos, SKUs de proveedor internacional, variantes (talla, color, tipo de par) y carga masiva por lotes erradicará el 100% de los descuadres de stock y reducirá el tiempo de catalogación operativa de 15 horas semanales a menos de 1 hora semanal.

### 4. Delimitación de Alcance (Scope Bounds)

**In-Scope (Mandatorio para v0.1.0):**
- Panel de Administración Web responsivo para la gestión completa de inventario.
- API Backend transaccional para la orquestación del catálogo, variantes y stock en tiempo real.
- Esquema de base de datos relacional para Marcas, Modelos, Códigos SKU de proveedor internacional, Tallas (US/EU/COL), Colorways y Tipo de Par (par completo, pie izquierdo, pie derecho, muestra).
- Módulo de carga masiva/por lote de mercancía importada e imágenes asociadas con compresión optimizada.
- Módulo de generación e impresión/descarga de colillas y comprobantes de pago transaccionales.
- Alertas de existencias mínimas por variante.

**Out-of-Scope (Estrictamente Prohibido para v0.1.0):**
- Landing page comercial pública y e-commerce B2C público (desarrollo independiente posterior).
- Integración de pasarelas de pago automáticas para clientes finales en la web pública.
- Aplicaciones nativas iOS / Android.
- Módulos de analítica predictiva de moda o inteligencia artificial.
