### 2. Stack Tecnológico Seleccionado (Gestor de Inventario Adi)
| Capa de Arquitectura | Tecnología Seleccionada | Justificación Técnica |
| --- | --- | --- |
| **Backend / API** | Node.js (TypeScript) / Python (FastAPI) / Java | Alta eficiencia en operaciones I/O relacionales y estructuración sólida de modelos |
| **Base de Datos** | PostgreSQL / SQLite | Soporte relacional nativo estricto para variantes de calzado (Marcas, SKUs, Tallas, Colores, Tipos de par) |
| **Frontend Administrativo** | JavaScript (React / Vue / HTML5-Vanilla) | Interfaz responsiva, dinámica y limpia para panel interno del operador |
| **Gestión de Código / CI-CD** | Git / GitHub | Control de versiones estricto y despliegue automatizado |
| **Almacenamiento de Medios** | CDN / Cloud Storage (WebP) | Almacenamiento optimizado de imágenes de tenis por lote |

### 3. Workflow de Desarrollo (Metodología)
- **Control de Versiones:** Gitflow con ramas `main`, `develop` y `feature/*`.
- **Estándar de Documentación:** Documentación en Markdown sincronizada en carpeta `/docs` por cada fase finalizada.
- **Formato de Entrega:** Entregables auditables por cada hito metodológico del SDLC.
