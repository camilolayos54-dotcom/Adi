# 12. Definición del MVP

### 1. Metadatos del Documento
**Proyecto:** Adi  
**Fase:** 1 — Viabilidad Temprana (Early Viability)  
**Entregable:** 12 de 18  
**Estado:** Aprobado  

### 2. Mandato del MVP (Hipótesis a Probar)
| Supuesto a Probar (Desde D11) | Experimento Asignado |
| --- | --- |
| S-01: Reducción del tiempo operativo a <1h/semana | Módulo de ingesta y carga masiva por lote con interfaz administrativa. |
| S-02: Cobertura del 100% de variaciones de calzado | Base de datos relacional con modelos para Marcas, SKUs, Tallas, Colores y Tipo de Par. |
| S-03: Control de ventas y colillas | Motor de comprobantes de pago y actualización transaccional de stock. |

### 3. Factor de Forma y Arquitectura Inicial
- **Form Factor:** Aplicación Web Administrativa (Gestor de Inventario / CRM de Calzado).
- **Herramientas a Alto Nivel:** JavaScript / HTML / CSS para la interfaz del gestor, Backend para lógica transaccional y Base de Datos Relacional para catálogo estructurado.

### 4. Barreras de Alcance (Scope Boundaries)
**In-Scope (Requerido estrictamente para el MVP):**
- Autenticación de usuario gestor (Login administrativo).
- Panel de gestión de catálogo: Marcas, Modelos, Códigos SKU de proveedor internacional.
- Gestión de variantes: Tallas (US/EU/COL), Colores (Colorway) y Tipo de Par (par completo, pie izquierdo, pie derecho, muestras).
- Módulo de carga masiva/por lote de mercancía e imágenes.
- Control de existencias (stock) en tiempo real con alertas de mínimo.
- Módulo de colillas/comprobantes de pago.

**Out-of-Scope (Estrictamente prohibido en esta fase):**
- Landing page comercial pública y e-commerce B2C público (desarrollo independiente posterior).
- Integración de pasarelas de pago automatizadas para clientes finales en la web pública.
- Módulos de analítica predictiva de tendencias de moda o inteligencia artificial.

### 5. Criterios de Salida (Exit Criteria)
| Métrica (De D11) | Umbral de Éxito | Acción si Pasa (Proceed) |
| --- | --- | --- |
| Tiempo de Registro de Lote (50 pares) | < 5 minutos | Autorizar avance a Fase 2 (Kickoff) |
| Inconsistencia de Stock | 0 descuadres | Aprobar arquitectura relacional de existencias |
